ETHICAL DECISION PROCESS — 4-STEP MODEL

4-Step Ethical Decision Process — Applied

Applied to Ocular's most significant risk: user image privacy

1

Identify the Issue

User images uploaded to Ocular may contain private or confidential content — medical records, legal documents, financial data.

2

Analyze Stakeholders

Users — privacy at risk  |  Developers — liability  |  OpenAI — API recipient of image data

3

Evaluate Alternatives

A) Send full image to GPT-4o — convenient, less private
B) Local OCR only — private, but less intelligent
C) Hybrid — local OCR first, API for structure only ✓

4

Justified Decision ✓

Hybrid approach chosen. Images encoded in-memory, never saved to disk. API key protected via .env. Risk minimised while retaining AI intelligence.

Remote Collaboration & Green Computing

Remote Collaboration

  • Team coordination via shared codebase and messaging apps
  • Challenge: code conflicts and communication gaps across schedules
  • Lesson: structured commits + clear task ownership are essential
  • Next step: move to GitHub with branch-per-feature workflow

Green Computing in Ocular

  • Local preprocessing (OpenCV) runs without any API call
  • GPT-4o Vision is only invoked when local OCR confidence is low
  • No permanent cloud storage of user documents
  • Fewer API calls = less server energy = lower carbon footprint
Result: The hybrid intelligence tier directly reduces energy consumption.
LEGAL ASPECTS OF COMPUTING

Our Legal Responsibilities as Developers

Building Ocular means accepting legal obligations — not just technical ones

📄

Data Protection

User images are processed locally. Not stored or transmitted without explicit need. This is our legal and moral baseline — not optional.

👤

User Rights

Users must be able to understand how the system processes their documents and must have a clear way to delete any retained data.

⚖️

Accuracy Liability

If OCR output is wrong and a user relies on it for official purposes, the tool's limitations must be clearly disclosed in the interface.

Ocular currently displays a confidence score and labels fallback results. This is our first step toward transparency compliance — further legal review would be required before any commercial deployment.
